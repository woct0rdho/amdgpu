# Fork of [amdgpu](https://github.com/ROCm/amdgpu) non-mainline dkms driver for PC sampling on gfx1151 (Strix Halo)

The non-mainline driver is based on Linux kernel 6.16 . We should use the latest mainline driver https://github.com/woct0rdho/linux-amdgpu-driver , which fixes an issue about CWSR on gfx1151, see https://github.com/ROCm/ROCm/issues/5590 .
